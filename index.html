09 — Workshop Flyer Direction

Flyer Layout System

Workshop flyers follow a three-zone layout: a bold hero gradient header with AI visual, a feature grid section for benefits, and a strong CTA footer with contact details and QR code.

1
Hero Zone

Deep navy–electric blue gradient background. Event name in large Sora ExtraBold. Badge for "100% GRATIS" in high-contrast yellow. AI illustration or student photo as visual anchor.

2
Feature Grid

2×2 or 2×3 rounded cards on light background. Icon (colored) + heading + brief description. Alternating blue/purple icon accent colors.

3
CTA Footer

Blue gradient strip with main CTA button. Contact row: WhatsApp, website, email. Social icons (Instagram, TikTok, YouTube) + QR code for registration.

4
Typography Rules

Event name: Sora 800, 48–64pt. Subtitle: Plus Jakarta 400, 14–16pt. Feature heads: Sora 700, 13–14pt. CTA button: Sora 800, 14pt uppercase.

11 / Guidelines 11 — Consistency Rules

Brand Do's & Don'ts

✅
Always Do
  • Use the approved blue-to-purple gradient as the primary energy carrier in all hero sections
  • Keep Sora ExtraBold/800 for all major headlines; maintain hierarchy consistency across formats
  • Add the social footer (Instagram, TikTok, website, phone) on every promotional post and flyer
  • Use rounded corners (16–20px) on all cards, buttons, and UI elements for brand consistency
  • Apply subtle glassmorphism effects on dark backgrounds for depth and modernity
  • Leave generous white space — clean, uncluttered layouts communicate trust and professionalism
  • Use real student/teacher photos with natural, authentic smiles and interactions
🚫
Never Do
  • Use dark, aggressive cyberpunk or hacker aesthetics — this conflicts with the educational warmth
  • Mix more than 3 primary colors in a single composition; keep it blue-dominant with purple accents
  • Stretch, crop, or alter the circular AI Mentoring logo proportions in any way
  • Use more than 2 typeface families in a single design — Sora + Plus Jakarta Sans only
  • Apply text on busy photo backgrounds without a gradient overlay for readability
  • Use red, orange or green as accent colors — these fall outside the brand palette entirely
  • Overcrowd compositions with too many graphic elements, effects, or decorative assets
Pre-publish Checklist
✓ Brand colors used
✓ Correct typeface
✓ Logo present
✓ Footer included
✓ CTA visible
✓ Rounded corners
✓ White space ok
